# Гавань — расслабляющий город-у-моря билдер

Неспешный офлайн-градостроитель: заложите маленький посёлок на побережье,
стройте дома, фермы и лесопилки, следите за едой, материалами и золотом,
а между ходами вас будут ждать мелкие случайные события — хороший урожай,
торговый караван, редкий шторм. Никаких таймеров, рекламы и интернета —
партия целиком идёт локально в браузере или в приложении.

## Стек

- React + TypeScript + Vite
- Tailwind CSS 4 для интерфейса
- Игровая карта рисуется на `<canvas>` пиксель-артом, сгенерированным
  программно (без внешних ассет-паков — полностью офлайн и без лицензионных
  рисков)
- Zustand для состояния партии, Dexie (IndexedDB) + localStorage для
  автосохранения одного текущего слота
- Шрифты Press Start 2P / Pixelify Sans подключены локально через
  `@fontsource` (кириллица включена, работает без сети)

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build   # статическая сборка в dist/
```

## Сборка APK (Capacitor)

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
Приложение не делает сетевых запросов и полностью работает в самолёте.

## Геймплей вкратце

- Ход = «неделя»: жмите «Дальше», когда готовы.
- Ресурсы: материалы, еда, золото, население (растёт при жилье и сытости).
- Здания: дом, ферма, лесопилка, каменоломня, рынок, колодец, таверна, маяк.
- Цель — 60 жителей или все виды построек, но играть можно и дальше без
  «game over».
